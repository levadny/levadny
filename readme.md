# About me

Hi. I'm Konstantin Levadny, a software engineer and researcher specializing in embedded software development for automotive and special-purpose vehicles. My research focuses on optimization algorithms. I have hands-on experience with C/C++, Linux, Git, the Qt framework, genetic algorithms, CAN and J1939.
